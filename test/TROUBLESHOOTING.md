# 飞书机器人收不到消息排查指南

## 排查清单

### 1. 检查 WebSocket 模式是否开通 【最常见原因】

**位置：** 飞书开放平台 → 应用详情 → 事件订阅 → WebSocket模式

**必须完成：**
- [ ] 点击"WebSocket模式"查看是否已开通
- [ ] 如果未开通，点击"立即开通"
- [ ] 获取 `WebSocket地址`（类似：`wss://open.feishu.cn/open-apis/bot/v3/horse/get?app_id=cli_xxxx&...`）

### 2. 检查事件订阅

**位置：** 飞书开放平台 → 应用详情 → 事件订阅

**必须订阅：**
- [ ] `im.message.receive_v1` - 接收消息事件
- [ ] 订阅后点击"保存"

### 3. 检查应用权限

**位置：** 飞书开放平台 → 应用详情 → 权限管理 → 权限配置

**必须开通：**
- [ ] `获取与发送单聊、群组消息` (im:message)
- [ ] `接收消息` (im:message)
- [ ] 点击"申请权限"（如果是内部应用通常自动通过）

### 4. 检查应用是否发布

**位置：** 飞书开放平台 → 应用详情 → 版本管理与发布

**必须完成：**
- [ ] 创建版本
- [ ] 发布应用
- [ ] 状态显示为"已发布"

### 5. 检查程序连接状态

运行程序后查看日志：
```
[DEBUG] connect to: wss://open.feishu.cn/...
[DEBUG] connected successfully
```

如果看到这些日志说明连接正常。

### 6. 检查消息类型

**P2消息要求：**
- 必须是用户对机器人发送的**单聊消息**
- 机器人在群里说话不会触发
- 用户在群里@机器人不会触发（除非群聊机器人）

### 7. 添加机器人到联系人列表

- 在飞书中搜索你的机器人应用
- 添加到联系人列表
- 打开单聊对话框发送"测试"

## 常见问题

### Q: 程序启动正常，但收不到消息
**A:** 检查 WebSocket 模式是否已开通，这是最常见的原因

### Q: 程序启动报错
**A:** 检查环境变量是否正确配置，APP_ID格式应为 `cli_xxxxx`

### Q: 连接成功但立即断开
**A:** 检查网络是否能访问飞书服务器 `wss://open.feishu.cn`

### Q: 能收到其他事件但收不到消息
**A:** 检查 `im.message.receive_v1` 是否已订阅

## 测试步骤

1. **确认环境配置**
```powershell
echo $env:FEISHU_APP_ID
echo $env:FEISHU_APP_SECRET
```

2. **启动程序并观察日志**
```powershell
.\larkbot-test.exe
```

看到 `[DEBUG] connected successfully` 表示连接成功

3. **发送测试消息**
   - 在飞书中找到你的应用
   - 打开单聊对话框
   - 发送任意文字

4. **观察控制台输出**
   - 应该看到 `[ OnP2MessageReceiveV1 access ]` 日志
   - 包含完整的消息JSON数据
