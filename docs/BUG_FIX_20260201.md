# Bug 修复说明

## 修复的问题

### 1. 已完成任务仍输出"已等待X分钟"

**原因：**
- `SendMessageStreaming` 中的 ticker 在任务完成后仍然触发
- StreamingSessionHandler 没有检查事件的 SessionID，处理了其他 session 的事件

**修复：**
- 在 HandleEvent 开始处增加 SessionID 检查，只处理当前 session 的事件
- 在 ticker 的 case 中检查 `handler.HasSentContent()`，如果已通过事件流发送内容，则不再发送进度提示

### 2. 每次都输出大量技能提示信息

**原因：**
- `enableSkillHint` 默认为 `true`
- 会在前3条消息中添加完整的技能列表，格式如下：
  ```
  [可用技能提示] 如果需要，你可以使用以下技能：
  - build (构建项目)
  - plan (规划任务)
  - websearch (网络搜索)
  ... 等等
  ```

**修复：**
- 将 `enableSkillHint` 默认值改为 `false`
- 如需启用，可以调用 `client.SetSkillHintEnabled(true)`

## 修改的文件

1. **internal/opencode/event_listener.go**
   - `HandleEvent()` 增加 SessionID 检查

2. **internal/opencode/client.go**
   - `SendMessageStreaming()` 的 ticker case 中增加 HasSentContent 检查
   - `NewClient()` 中将 enableSkillHint 改为 false

## 测试建议

1. 重新编译并运行 gateway
2. 发送一个测试消息，观察：
   - 任务完成后是否还有"已等待"提示
   - 回复内容中是否还有技能列表提示
3. 如需启用技能提示，在创建 client 时传入 `WithSkillHint(true)` 选项
