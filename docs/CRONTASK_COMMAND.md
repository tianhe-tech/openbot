# /crontask 命令使用指南

## 概述

`/crontask` 命令允许你直接在聊天中创建和管理定时任务，无需调用 API。

当前支持平台：
- DingTalk（钉钉）
- Feishu（飞书）
- WeCom（企业微信）

除了结构化命令，也支持自然语言：

```
每天早上9点提醒我检查系统
列出我的定时任务
禁用任务 cron-1746000000
```

写操作默认先返回“草稿”，需用户确认后执行：
- 执行：`确认` / `yes` / `1`
- 取消：`取消` / `no` / `0`

## 命令格式

```
/crontask <子命令> [参数...]
```

自然语言兜底格式：

```
/crontask <自然语言描述>
```

示例：

```
/crontask 每天早上9点提醒我生成日报
```

## 可用子命令

### 1. 添加定时任务

```
/crontask add "cron表达式" "任务名称" "任务内容"
```

**示例：**
```
/crontask add "0 */30 * * * *" "系统监控" "查看系统负载和内存使用情况"
/crontask add "0 0 9 * * *" "每日报告" "生成昨天的工作总结"
/crontask add "0 0 18 * * 1-5" "下班提醒" "提醒检查今日任务完成情况"
```

### 2. 列出所有定时任务

```
/crontask list
```

显示当前 adapter（当前平台）的所有定时任务，包括：
- 任务 ID
- 任务名称
- Cron 表达式
- 状态（启用/禁用）
- 下次执行时间

### 3. 查看任务详情

```
/crontask info <任务ID>
```

**示例：**
```
/crontask info task-123456789
```

### 4. 禁用定时任务

```
/crontask disable <任务ID>
```

**示例：**
```
/crontask disable task-123456789
```

### 5. 启用定时任务

```
/crontask enable <任务ID>
```

**示例：**
```
/crontask enable task-123456789
```

### 6. 删除定时任务

```
/crontask delete <任务ID>
```

**示例：**
```
/crontask delete task-123456789
```

### 7. 查看帮助

```
/crontask help
```

## Cron 表达式格式

Cron 表达式由 6 个字段组成：

```
秒 分 时 日 月 周
```

### 字段说明

| 字段 | 范围 | 特殊字符 |
|------|------|----------|
| 秒 | 0-59 | * , - / |
| 分 | 0-59 | * , - / |
| 时 | 0-23 | * , - / |
| 日 | 1-31 | * , - / ? |
| 月 | 1-12 | * , - / |
| 周 | 0-6 (0=周日) | * , - / ? |

### 特殊字符含义

- `*` : 匹配所有值
- `,` : 列举多个值，如 `1,3,5`
- `-` : 范围，如 `1-5`
- `/` : 步长，如 `*/5` 表示每 5 个单位
- `?` : 不指定值（仅用于日和周）

### 常用示例

```
0 0 * * * *        # 每小时整点
0 */30 * * * *     # 每 30 分钟
0 0 9 * * *        # 每天早上 9 点
0 0 18 * * 1-5     # 周一到周五下午 6 点
0 0 0 1 * *        # 每月 1 号零点
0 0 9,18 * * *     # 每天早上 9 点和下午 6 点
```

## 使用场景

### 1. 系统监控

```
/crontask add "0 */10 * * * *" "系统状态" "检查服务器 CPU、内存、磁盘使用情况"
```

每 10 分钟检查一次系统状态。

### 2. 定期报告

```
/crontask add "0 0 9 * * 1" "周报提醒" "提醒准备本周工作报告"
```

每周一早上 9 点提醒。

### 3. 数据备份提醒

```
/crontask add "0 0 2 * * *" "备份提醒" "提醒检查数据库备份是否成功"
```

每天凌晨 2 点提醒检查备份。

### 4. 日程提醒

```
/crontask add "0 30 17 * * 1-5" "每日总结" "发送今日工作总结"
```

工作日下午 5:30 提醒。

## 工作流程

1. **添加任务**：使用 `/crontask add` 创建新的定时任务
2. **系统处理**：
   - 解析命令参数
   - 验证 cron 表达式
   - 创建 ScheduledTask 对象
   - 注册到 CronScheduler
3. **定时执行**：
   - CronScheduler 在指定时间触发任务
   - 创建新的 OpenCode session
   - 执行任务内容（AI 处理）
   - 将结果发送回钉钉群
4. **草稿确认**：写操作先生成草稿，等待用户确认或取消
5. **管理任务**：使用 list/enable/disable/delete 管理任务

## 注意事项

1. **权限**：确保你有足够的权限在群内创建定时任务
2. **Cron 表达式**：使用引号包裹 cron 表达式，避免被错误解析
3. **任务内容**：任务内容会发送给 OpenCode AI 处理，确保内容清晰明确
4. **执行频率**：不要设置过于频繁的任务（如每秒执行），会消耗大量资源
5. **任务数量**：合理控制定时任务数量，避免系统负载过高

## 错误处理

如果命令执行失败，系统会返回错误信息：

- `参数格式错误`：检查命令格式和参数数量
- `无效的 cron 表达式`：检查 cron 表达式格式
- `任务不存在`：检查任务 ID 是否正确
- `添加定时任务失败`：检查系统日志，可能是调度器未启动

## 与 REST API 的关系

`/crontask` 命令在后台调用以下 REST API：

- `POST /api/scheduled-tasks` - 添加任务
- `GET /api/scheduled-tasks` - 列出任务
- `PUT /api/scheduled-tasks/{id}/enable` - 启用任务
- `PUT /api/scheduled-tasks/{id}/disable` - 禁用任务
- `DELETE /api/scheduled-tasks/{id}` - 删除任务

你也可以直接调用这些 API 进行管理。
