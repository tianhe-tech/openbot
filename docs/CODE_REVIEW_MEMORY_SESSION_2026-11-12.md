## 当前状态

两个功能的缺陷修复在**单元层面**完成：`go build ./cmd/... ./internal/...`、`go vet ./cmd/... ./internal/...` 无输出，相关包测试全部通过。`gofmt -l` 仍列出约 60 个文件，均为仓库既有的 CRLF 换行差异（`core.autocrlf` 造成），逐字节核对不含真实格式问题。

注意 `internal/memstore` 必须单独以 `-timeout 40m` 运行：该包构建真实归档并运行索引 worker，耗时超过 Go 默认的 10 分钟（本轮实测 `ok 852.833s`），省略参数会以包级超时 panic 结束，看起来像某个测试失败。

以下各项**仍未验收**，单元测试通过不构成验收：真实平台端到端（飞书/钉钉/企微无包内测试）、双进程失租隔离、`-race`（本机无 gcc）、进程重启语义、生产规模数据库升级、真实 iLink 入站崩溃窗口。详见各报告的“待验收项”。
